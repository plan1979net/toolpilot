# ToolPilot

English-language static software discovery directory with a browser-side Tool Finder, original starter guides and transparent referral links.

## Run
Serve the repository root with any static HTTP server. No build or dependencies required.

## Deploy
Cloudflare Pages: connect this repository, choose no framework, leave build command blank, set output directory to `/`.

## Before launch
Replace the placeholder sitemap URL with the actual production domain, update canonical/OG URLs after domain selection, confirm all affiliate programs and link destinations, check current provider details, and configure a private contact method if desired.

## Content
Tool data is in `data/tools.json`. Each outbound referral link is marked `rel="sponsored nofollow noopener noreferrer"`.
